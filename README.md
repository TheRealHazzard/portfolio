# Portfolio

Personal portfolio of Robin Thomas, senior front-end engineer. Built with Next.js, React 19, TypeScript, Tailwind CSS, Framer Motion and Three.js.

**Live: https://therealhazzard.github.io/portfolio/**

Lighthouse (mobile, live site, Nov 2026): performance 99, accessibility 100, best practices 100, SEO 100.

**Sections:** hero, about, experience timeline, outcome-focused case studies, skills and contact, with a light/dark theme toggle.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Page content lives in `src/lib/data.ts`.

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Framer Motion · React Three Fiber
